# etoile-data

Data files for stars and constellations.

## Stars

Star JSON files live in `data/stars/`. Schema: `data/stars.schema.json`.

Generated by `scripts/fetch_named_stars.ipynb`.

Sources used:

- **SIMBAD** via `astroquery.simbad`
  - named stars and Bayer-designated stars
  - manually listed interesting objects
  - identifiers: Gaia DR3, Gaia DR2, HD, HIP, Gliese/GJ, 2MASS, WR
  - coordinates, parallax, spectral type, object type
- **Gaia DR3** via `astroquery.gaia`
  - preferred RA/Dec/parallax when available
  - `radius_flame`, `lum_flame` when available
- **Gaia DR2** via `astroquery.gaia`
  - fallback RA/Dec/parallax
- **Hipparcos** via VizieR `I/239/hip_main`
  - fallback RA/Dec/parallax
  - B-V color index
  - spectral type comparison field
- **HYG v4.1**
  - seed list of stars with proper names or Bayer designations
  - fallback coordinates, distance/parallax, luminosity, B-V-like color index, spectral type

Processing done:

- Seeded star list from HYG named/Bayer stars.
- Added SIMBAD named/Bayer stars and manually listed interesting objects.
- Deduplicated rows using connected identifiers across Gaia, HIP, HD, Gliese/GJ, 2MASS, WR, and SIMBAD OID.
- Queried Gaia DR3/DR2 and Hipparcos for higher precision measurements.
- Chose source values by priority, keeping source fields like `ra_source`, `parallax_source`, etc.
- Filtered non-stars mainly using SIMBAD object type.
- Picked the most informative spectral type from SIMBAD, HYG, or Hipparcos.
- Classified spectra into spectral class, luminosity class, star type, and spectral peculiarities, including multi-star `+` spectra, white dwarfs, Wolf-Rayet stars, carbon stars, subdwarfs, and brown dwarfs.
- Built display names from common name, Bayer name, lookup name, or catalog IDs.
- Wrote one JSON file per star to `data/stars/`.

## Constellations

Constellation JSON files live in `data/constellations/`. Schema: `data/constellations/schema.json`.

Generated by `scripts/fetch_constellations.ipynb`.

Sources used:

- **D3 Celestial**
  - IAU constellation metadata
  - boundary polygons
- **Stellarium `modern_iau` skyculture**
  - constellation line paths using HIP IDs
  - common/native names and meanings
- **HYG v4.1**
  - brightest star per constellation

Processing done:

- Converted constellation metadata into one row per IAU constellation.
- Converted boundary GeoJSON coordinates into JSON-friendly RA/Dec rings.
- Preserved Stellarium line paths as HIP ID paths/segments.
- Picked brightest star per constellation from HYG by lowest visual magnitude.
- Added Bayer display names with Greek symbols where possible.
- Wrote one JSON file per constellation to `data/constellations/`.
